### 들어가기전에..

```javascript
<!DOCTYPE html>
<html>
<head>
    <meta name="viewport" content="width=device-width"/>
    <meta charset="utf-8">
    <title>06-type</title>
    <script src="https://unpkg.com/babel-standalone@6.15.0/babel.min.js"></script>
</head>
<body>
<h1>06-type</h1>
<p>Open the console</p>
<script type="module">

</script>
</body>
</html>
```
자바 스크립트 타입을 선언할때 종류가 3가지가 있다.

- script type="module"
  
- script type="text/babel"
  
- script type="text/javascript"

이 3가지는 기능과 사용성이 다르다.

### type="text/javascript"

옛날 방식의 일반 스크립트이다. 파일이 위에서 아래로 읽으며 즉시 실행시킨다. 간단한 웹페이지나 작은 기능에 주로 사용된다.

### type="module"

최신 방식의 모듈 스크립트이다. 코드를 작은 모듈로 쪼개서 관리한다. 코드를 즉시 실행하지 않고 필요한 부분만 불러와서 나중에 실행시킨다. 

### type="text/babel"

새로운 문법을 옛날 문법으로 바꿔주는 도구다. 옛날 브라우저가 알아들을 수 있는 코드다.


<u>가장 중요한 점은 text/babel 타입(즉, Babel을 사용하는 환경)에서 변수 호이스팅과 관련해 let과 const를 허용해준다는 것이다.</u>

var는 원시 자바스크립트(JS) 시대부터 존재해 모든 브라우저와 100% 호환된다.

하지만 let과 const는 ES6(2015) 이후 도입된 문법으로, 오래된 브라우저에서는 기본적으로 지원되지 않는다.

따라서 과거에는 Babel 같은 빌드 툴을 이용해 let과 const를 var로 변환해야만 안전하게 사용할 수 있었다.

현재는 최신 브라우저들이 let과 const를 기본적으로 지원하기 때문에 별도의 빌드 과정 없이 바로 사용해도 문제가 없다. 
일단 자바 스크립트를 사용한다고 알아두자.
